# Changelog

## 1.1
- Interface in three languages: English (default), Español, Русский — asked on first run, change any time with `l`.
- `Backspace` on an empty prompt goes back in every menu.
- **Google services** manager: find all Google packages, see the risk level, remove selectively (`1-7`, `1 4 9`) or all safe ones, and restore removed ones.
- Open the **Aerial web panel** (port 8790) in the browser, from the main screen or for the selected TV.
- About screen, author and MIT license.

## 1.0
- Network discovery of Android TVs with ADB, Cast, Android TV Remote and Aerial detection per IP.
- Manual connection (IP + port) and Android 11+ wireless debugging pairing.
- APK installation with progress bars (single, multiple, whole folder; `.apk`, `.apks`, `.apkm`, `.xapk`).
- Apps: open on TV, versions, stop, uninstall; system apps view with search.
- Launcher switching, device information, TV restart.
